# Portside Fusion

Website for Portside Fusion, casual fine dining in Port Carling, Muskoka.

Next.js (App Router) + TypeScript, deployed on Vercel. Fully static.

- `app/page.tsx` - the page (hero video, visit, welcome, winter menu, cocktails + desserts, reservations, footer)
- `data/menu.ts` - the winter menu, cocktails and desserts. Edit prices and dishes here.
- `data/site.ts` - address, phone, hours, socials and the OpenTable booking link
- `app/globals.css` - design system, responsive breakpoints and scroll animations
- `public/images`, `public/video` - photography and the hero loop

```bash
npm install
npm run dev
```
